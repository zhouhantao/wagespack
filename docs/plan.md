# wagespack M0–M4 开发计划

按任务书开发。补充设计规范尚未收到。按当前范围优先落地桌宠，再扩展工资与设置。

| 阶段 | 文件与任务 | 验收 |
|---|---|---|
| M0 | spikes/tauri-transparent 提供独立透明角色窗和普通信息窗。记录启动、命中和拖拽表现 | MSVC 编译，实际启动，测透明背景、置顶、按下拖动和 Esc 收起。记录环境和多屏限制 |
| M1 | src/core/schedule.ts 把时区班次拆成有效时间段，src/core/earnings.ts 按 Decimal 计算，src/ui 提供引导及点击面板 | Vitest 覆盖午休、跨日月、DST、零薪资、请假与时间跳变。Playwright 验证点击、关闭、持久化 |
| M2 | src-tauri 管理透明窗口、托盘、工作区位置及恢复，src/platform 封装浏览器和桌面差异，src/pet 管理状态与动画 | 桌面冒烟验证角色点击与拖拽、窗口与托盘恢复、位置重启恢复、多屏 DPI、动画关闭 |
| M3 | src/ui 增加日历、愿望、历史、语言、主题与隐私。src/pet/character-pack.ts 验证导入并预览，可更换和删除 | 校验图片真实格式、像素及总量限制。优先本地独立文件图集和清单格式，避免引入解包攻击面。测试坏数据回退与键盘操作 |
| M4 | .github/workflows 只配置本地可复现的构建和测试，补齐文档、截图、Windows EXE 和 SHA256 | 全量测试、Web 构建、EXE 启动、复查素材许可和 Git 状态 |

## 窗口方案

先试 Tauri 2 + WebView2。保持角色窗紧贴统一动画画布，面板作为独立窗口，仅展开时显示。若透明角落拦截鼠标，记录实际范围，评估原生 Win32 分层窗口处理角色渲染和逐像素命中，保留同一面板和核心逻辑。

## 四张角色参考

- 图 1 男生近四头身，暖棕蓬松偏分发、橄榄工装外套、白 T、炭灰长裤和米白球鞋。招手参考采用抬手笑、再回到原站姿。指向和后仰用于后续事件。坐姿相邻帧只变手腕和肩部，椅脚固定。
- 图 2 上女下男，同向行走。参考接触与后脚抬起的姿势。保留鞋落地基线，头肩轻微起伏，发尾、裙摆、衣角滞后。图内是姿势参考，循环需要另做明确的左右换脚和过渡。
- 图 3 上女下男，左右朝向站立，以及坐姿捧杯与抬杯。女生深棕长发、奶油针织外套、墨绿长裙、棕靴、棕色斜挎包和耳饰。方向切换保持包带一致。杯子从胸前抬到嘴边，椅子和前脚稳定，原路径放下。
- 图 4 女生坐姿打字、用力、扶额、趴伏，以及叉腰和受惊。常态工作采用打字的小幅循环。大幅情绪动作留作独立事件，避免连续重击。
- 角色须用暖褐描边和有限色阶做柔和像素体积感。每个动作先画关键帧，再按统一画布的足底中心和椅脚对齐。实测每帧可视轮廓与透明边缘，原图不按网格机械裁剪。内置原创资源与私有参考分离。
